# PAAMPdb

## Curated Antimicrobial Peptides Targeting *Pseudomonas aeruginosa*

**PAAMPdb** is a curated database resource specializing in experimentally reported antimicrobial peptides (AMPs) targeting *Pseudomonas aeruginosa*. The database brings together curated experimental information on reported AMPs, including antimicrobial effectiveness, peptide-related information, structural models, and residue-level interactions between AMPs and target proteins.

## Database

The PAAMPdb web resource is available at:

https://mgbio.asab.nust.edu.pk/paampdb

## GitHub Repository

The source code and associated project files are available at:

https://github.com/samavinasir/paampdb.git

## Key Features

- **Curated AMP information**  
  Provides curated information on antimicrobial peptides reported against *P. aeruginosa*.

- **Antimicrobial activity**  
  Includes experimental information describing the antimicrobial effectiveness of reported peptides.

- **Peptide information**  
  Provides relevant peptide-level information for exploring and comparing AMP candidates.

- **Structural models**  
  Includes a range of homology-based structural models associated with AMP-related analyses.

- **AMP–target interactions**  
  Provides residue-level information describing interactions between antimicrobial peptides and their target proteins.

- **Search and exploration**  
  Enables users to explore the curated database and identify AMPs of interest for further investigation.

## Research Applications

PAAMPdb is intended to support research in:

- Antimicrobial peptide discovery
- *P. aeruginosa* research
- Antimicrobial resistance studies
- AMP–protein interaction analysis
- Structural bioinformatics
- Therapeutic target exploration
- Development of alternative antimicrobial strategies

## Target Organism

The database focuses specifically on ***Pseudomonas aeruginosa***, an important bacterial pathogen associated with antimicrobial resistance and clinically relevant infections.
